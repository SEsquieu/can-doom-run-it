# Can DOOM Run It?

A standalone GZDoom derivative exploring DOOM as a spatial hardware/software control interface.

Based on official [GZDoom](https://github.com/ZDoom/gzdoom) `g4.14.2`.
The complete upstream history and the original project README commit are preserved.
See the [upstream README](docs/upstream/README.md) and the original license files for attribution and licensing.
