# Can DOOM Run It?

A standalone GZDoom derivative exploring DOOM as a spatial hardware/software control interface.

The goal: download, launch, enter DOOM, and control something without manual
configuration. Bootstrap establishes a native application and development
foundation; the bundled control playground and polished first-run experience
are still to come.

- [Build on Linux or Windows](docs/BUILDING.md) (or open `.devcontainer/`)
- [Architecture and first-run plan](docs/ARCHITECTURE.md)
- [Native control-output demo](docs/CONTROL_OUTPUT.md): press Use, observe JSON over loopback UDP
- [Free game assets and redistribution](docs/ASSETS.md)
- [Upstream provenance and updates](docs/UPSTREAM.md)
- [Contributor conventions](AGENTS.md)
- [Recorded validation and environment limits](docs/VALIDATION.md)
